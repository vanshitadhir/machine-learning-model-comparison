# Machine Learning Model Accuracy Comparison

## Overview
This project compares four machine learning classification algorithms and evaluates their performance using test accuracy.

## Algorithms Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

## Model Accuracy Results

| Model | Accuracy |
|---|---:|
| KNN | 89.13% |
| Logistic Regression | 88.59% |
| Random Forest | 88.59% |
| Decision Tree | 77.72% |

## Best Model
K-Nearest Neighbors (KNN) achieved the highest test accuracy of **89.13%** in this experiment.
